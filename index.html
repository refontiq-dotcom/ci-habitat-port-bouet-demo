Les règles qui protègent le programme

Des clauses strictes pour garantir le caractère social et éviter la spéculation.

Zéro frais d’entrée

Aucun apport, caution, frais de dossier ou avance. Vous emménagez et commencez à payer.

Un logement par foyer

Contrôle anti-cumul strict via CNI des conjoints. Un seul logement par foyer, pour tous les Ivoiriens.

Interdiction de revente 50 ans

Le bien reste social. Aucune spéculation possible. Verrouillage technique dans le système.

Transmission aux enfants

En cas de décès, le contrat est automatiquement transmis aux enfants déclarés. Zéro formalité complexe.

Ouvert à tous les Ivoiriens

Transparence totale

Deux phases, une trajectoire claire

Pour tous les Ivoiriens. Premier site à Port-Bouët. Une méthode solide du dépôt jusqu’à la remise des clés.

EN COURS
PHASE 1

Dépôt & tri des dossiers

Pendant que les logements se construisent, nous collectons et filtrons les candidatures de toute la Côte d’Ivoire. Objectif : une file d’attente propre, sans fraude, prête pour l’attribution.

  • Candidature 100 % mobile (OTP + pièces)
  • Filtre anti-doublon (CNI, téléphone, foyer)
  • Tri automatique puis revue humaine ciblée
  • Créneaux de visite limités (pas de file anarchique)
  • Suivi chantier visible pour rassurer (« 0 risque »)
ENSUite
PHASE 2

Attribution, contrats & paiements

Quand les logements sont prêts, les dossiers validés passent à l’attribution. Signature du contrat de location-vente, emménagement, puis paiement mensuel sur 120 mois via Mobile Money.

  • Attribution selon file et typologie (studio / 2p / 3p)
  • Contrat 120 mois + clause succession enfants
  • Échéancier automatique + push Mobile Money
  • Relances SMS / WhatsApp (J-3, J, J+3)
  • Verrou anti-revente 50 ans dans le système
Message clé pour le comité
On ne construit pas d’abord pour gérer le chaos ensuite. On structure les dossiers pendant le chantier, pour attribuer sereinement à la livraison.
